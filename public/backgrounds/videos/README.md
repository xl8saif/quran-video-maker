# Waraq Quran Reel Maker — Video Backgrounds

Place Pixabay/Pexels or other properly licensed background videos in this folder.

Recommended formats:
- `.mp4` (preferred)
- `.webm`

For each video, keep a record of the source URL and license/usage terms before publishing it in the app.

Do not add videos unless their license permits the intended use, especially commercial/re-publishing use.
