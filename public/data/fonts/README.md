# Waraq Quran font assets

Waraq keeps Quran typography local so Quran rendering does not depend on a web font CDN.

Current repository assets:
- `../Amiri_Quran.zip` — uploaded Amiri Quran font package
- `../Noto_Nastaliq_Urdu.zip` — uploaded Noto Nastaliq Urdu font package

The UI font families are configured as:
- Arabic Quran text: `Amiri Quran`
- Urdu translation text: `Noto Nastaliq Urdu`
- Indo-Pak Quran text: `Muhammadi Quran`

A Muhammadi Quran TTF/ZIP is still required in this repository before it can be loaded as a local web font. Do not substitute an unlicensed font package.

For Amiri Quran, use the font package already supplied in `public/data/Amiri_Quran.zip`.
For Urdu, use the package already supplied in `public/data/Noto_Nastaliq_Urdu.zip`.
